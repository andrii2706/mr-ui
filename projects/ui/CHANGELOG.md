# Зміни @mr/ui

## 0.3.0

- Перемикач застосунків `ui-app-switcher` (current, rail): «Портал» і відкриті модулі акаунта (портал віддає їх у
  `GET /api/portal/auth/access`), модуль — через SSO порталу; той самий вигляд у всіх чотирьох застосунках.
- Лоадери переходів: `[uiLeave]` на посиланні в інший застосунок — одразу заставка «Відкриваємо «…»…» /
  «Повертаємо на портал…» з іконкою (`UiActivityService.leave()`), «назад» з кешу браузера її прибирає.
- Лоадери дій: `uiActivityInterceptor` — тонка смужка вгорі на кожен POST / PUT / PATCH / DELETE (після 200 мс,
  щонайменше 400 мс); `UI_QUIET_REQUEST` — запит без смужки. Обидва лоадери показує `ui-activity-host`.
- peerDependencies: `rxjs`.

## 0.2.0

- Пакет `@andrii2706/mr-ui` у GitHub Packages (приватний). Застосунки ставлять його як `"@mr/ui": "npm:@andrii2706/mr-ui@^0.2.0"`,
  імпорт той самий — `from '@mr/ui'`; копії `src/mr-ui` і `scripts/sync.mjs` прибрано. Тема — `@import '@mr/ui/theme.css'`.
- Поле дати й часу `ui-date-input`: ДД.ММ.РРРР з маскою, календар (дні, місяці, роки, понеділок першим), години кроком 30 хв.
- Бездіяльність: `UiIdleService` (10 хв, попередження за 1 хв, спільний годинник для всіх вкладок домену, перевірка після сну
  й повернення на вкладку) і `ui-idle-host` — заставка одразу, без показу сторінки, далі портал.

## 0.1.0

- Окремий репозиторій `mr-ui`: бібліотека й галерея. Застосунки отримують копію через `scripts/sync.mjs` у `src/mr-ui`
  і імпортують `@mr/ui`; із platform/ портала `ui` прибрано.
- Тема: 4 модулі на daisyUI 5, контраст рамок полів (3,35 : 1) і плейсхолдерів (5,09 : 1), фокус, цілі ≥ 24 px, менше руху,
  Windows high contrast.
- Високий контраст: білий ґрунт, темніший текст, сірі рамки (#8a8e82) замість чорних обведень карток, бейджів і вкладок.
- «Доступність»: панель і сервіс — розмір тексту, контраст, рух, підкреслені посилання, інтервали тексту, сильніший фокус.
- Лоадери: сторінка (`ui-page-loader`), частина (`ui-skeleton-list`), кнопка (`[uiBusy]`), правило 200 / 400 мс.
- Довга дія: `LongActionService` + `ui-long-action-host`, сторінка поза досяжністю (inert), оголошення для читача екрана.
- Іконки: 57 контурних іконок + іконки модулів.
